# ZomarHousing — Streamlit starter

## Run locally
1. Open this folder in PyCharm.
2. Open the PyCharm Terminal.
3. Install dependencies:
   `py -m pip install -r requirements.txt`
4. Start the website:
   `py -m streamlit run app.py`

## Important
- Listings, prices, team profiles, contact details and property descriptions are demonstration content.
- Replace them with accurate, authorised business information before publishing.
- Images are loaded from Unsplash URLs and therefore require an internet connection.
- Enquiry forms currently show a demo confirmation. They do not yet send email or save enquiries.
